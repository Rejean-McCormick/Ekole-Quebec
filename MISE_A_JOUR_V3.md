# Québec — publication Élève de 3e année

- `pack.json` : politique `vues_separees`.
- `cours/*.json` : 202 sources historiques **inchangées**.
- `publications/eleve/` : trois leçons pilotes rédigées pour l'enfant, chacune six étapes.
- `integrations/spek-eleve.json` : fiche élève expérimentale distincte des neuf scénarios Spek experts.
- `brouillons/eleve/` : créé sur demande via l'atelier Enseignant et non servi publiquement.
- `publications/visuels/` : créé sur approbation d'une image et contient les empreintes des fichiers approuvés.
- `LANCER.bat` : consultation, lecture seule.
- `LANCER_ATELIER.bat` : mode `--edition` pour éditer/importer et publier après validation.

Les 33 autres cours de 3e n'ont pas de publication Élève pour le moment. La leçon affichera « en préparation » plutôt que son corrigé enseignant.
