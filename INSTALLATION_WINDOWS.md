# Démarrer Ekole Québec sous Windows

Placer ce dossier à `C:\mycode\Ekole\ekole-quebec` et le moteur aligné à `C:\mycode\Ekole\ekole`. Les missions utilisent aussi les dépôts voisins `Kontexte` et `Kompose`.

Installer Python 3.10+ puis double-cliquer sur `LANCER.bat`. Portail : `http://127.0.0.1:8765/`; atelier : port 8766, lien privé affiché dans la console. L’option `--edition` du lanceur autorise l’édition prévue des cours.

Pour le dépôt Git, installer Git LFS et suivre `docs/STOCKAGE_ET_NOUVEAU_DEPOT.md` **avant** `git add`. Le ZIP de livraison contient les vraies images disponibles dans le snapshot; aucune nouvelle planche de personnages n’a été générée.

Les 202 cours et leurs statuts sont conservés. Les archives livrées séparément se rangent en dehors du dossier du dépôt.
